# Bright Future Foundation Website

## Project Overview
Bright Future Foundation is a fully responsive NGO website built using HTML, CSS, and JavaScript. The website represents a fictional organization focused on education, healthcare, women empowerment, child welfare, and sustainable development.

This project was created as part of an AI Website Generation task to explore modern web development structure and frontend design practices.

## Features
- Fully responsive website design
- Modern landing page with hero section
- About section with organization details
- Mission, vision, and values section
- Multiple program/service sections
- Image gallery showcasing community impact
- Volunteer registration form with validation
- Contact form with structured input fields
- FAQ accordion section
- Donation section UI
- Testimonials section
- Dark mode toggle feature
- Smooth scrolling navigation
- Interactive UI using JavaScript

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome (Icons)
- Google Fonts
