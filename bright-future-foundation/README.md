# 🌟 Bright Future Foundation Website 🌟

A modern and responsive NGO website created using HTML, CSS, and JavaScript with the assistance of Claude AI.

This project was developed as part of my internship task to explore AI-powered website generation and understand practical web development concepts.

---

# 📌 Project Overview

Bright Future Foundation is a concept NGO website designed to spread awareness about:
- Education
- Social Welfare
- Volunteering
- Donation Initiatives

The website focuses on:
- Clean UI/UX Design
- Responsive Layout
- User-Friendly Navigation
- Modern Web Design Principles
- AI-Assisted Development
